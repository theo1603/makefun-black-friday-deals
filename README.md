Lantern Deals — a Black Friday deal finder with 33 real deals checked at their stores on 27 Nov 2026, each with its sale price, usual price, discount worked out from those two prices, store link, check time and source, plus an honest verdict (New low / Strong price / Routine sale) with the evidence behind it. Search and filters by category, store and discount all work; sorting puts the best deals first. Built by an AI agent for make.fun's "Build the best real Black Friday deal finder" bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the site is plain static files under `app/`, no build step and no network loads. To hand it in, run `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
